# http_api_kit agent skills

These skills describe the current public package API. Import it from consuming apps with:

```dart
import 'package:http_api_kit/http_api_kit.dart';
```

- `http-api-kit-repositories`: typed HTTP calls, response envelopes, uploads, downloads, and repository mapping.
- `http-api-kit-model-mapping`: conversion from backend payloads to app models and package pagination types.
- `http-api-kit-async-widgets`: loading, error, empty, refresh, numbered pagination, and infinite-scroll widgets.
- `http-api-kit-actions`: `CommandState` and `ActionState` command outcomes.
- `http-api-kit-riverpod-providers`: optional host-app Riverpod integration. Riverpod is not a dependency of this package.
